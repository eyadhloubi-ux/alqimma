# قعدة عالقمة · قعدة رواق

(اسمها القديم «مين فوق؟»)

لعبة فرق ومعلومات من مشروع «صار بدها قعدة» — إعداد م. إياد حلوبي.

من 2 لـ4 فرق، كل لاعب من موبايله. بكل جولة بينطرح نفس السؤال لعضو من كل فريق مع مؤقت:
الصح بيطلّع الفريق درجة، الغلط بينزّله درجة (وممكن يوصل للوادي تحت الصفر)، و«مرّر» ما بيربّح ولا بيخسّر. أول فريق بيوصل للقمة بيرفع علمه.

## شو فيها
- **الريس** بيفتح القعدة، بتطلعله QR وكود من 5 أحرف، وبيظبط: عدد الفرق، توزيع حر أو فرز عشوائي، المجالات (11 مجال)، «اختصاصات الفريق» (كل مجال بيصير اختصاص وكل فريق لازم يحجزهن كلهن قبل البداية؛ إذا الفريق أقل من الاختصاصات في حدا بياخد اتنين «دبل»، وإذا أكتر في اتنين بيتشاركوا وبيتناوبوا)، الصعوبة، وقت الجواب، ارتفاع القمة، الجولة الفاصلة أو الفوز المشترك، طقس الجبل، والجبل بالغيم (كشف بالآخر).
- **الجولات**: المجال بيطلع عشوائي ومفاجأة، بس كل المجالات بتاخد نفس العدد من الأسئلة.
- **خزينة 992 سؤال**: أديان، كيمياء، جغرافيا، فيزياء، تاريخ، أدب، رياضيات، رياضة، فن، عامة، أحياء — كل مجال 3 مستويات. والريس بيقدر يزيد أسئلته قبل وخلال اللعب.
- **طقس الجبل**: ريح طيبة (الصح +2)، عاصفة ثلج (الغلط −2)، ضباب (الوقت نصّه)، تلفريك (أول صح +1 زيادة).
- **أدوات الريس**: وقّف وكمّل، مرّر الجولة (بتنمسح كأنها ما صارت)، اكشف هلق، خلّصوا هون، سؤال من عندك، نقل لاعب، تعديل اسمه أو شيله، وتوزيع الاختصاصات الفاضية تلقائياً.
- **إذا طلع الريس** اللعبة ما بتوقف: بعد 40 ثانية بيطلع للباقيين زر «صير أنا الريس» وبيكمّلوا من وين وقفوا. وإذا رجع الريس القديم بيفوت كلاعب.
- **ثوابت رواق**: زر «؟» فوق فيه «كيف منلعب؟»، سيلفي من الكاميرا أو صورة من الموبايل، نوع قعدة بتكتبوه أنتو، وتنزيل كتطبيق.
- **النهاية**: حفلة كشف من تحت لفوق وعلم القمة، أو كشف دفعة وحدة، ونتيجة بالفرق وبكل الجولات، وألقاب لكل شخص.
- **صورة ستوري لكل فريق**: صورة الشلة (أو صور الأعضاء)، مرتبة الفريق، أعضاؤه وألقابهم، وجبال الترتيب لكل الفرق وفريقها مميّز: غلاف / بولاريد / كرت، فاتح وداكن، والريس بيشيل الألقاب اللي ما بدّو ياها.
- **جرّب لحالك**: افتح الرابط مع `?demo=1` وبتلعب مع لاعبين وهميين.
- **إحصائيات** بلا أسماء ولا صور على `/stats?key=…`.

## الرفع على GitHub
1. اعمل مستودع جديد على GitHub (مثلاً `alqimma`).
2. فك ملف الـzip، وارفع كل اللي جوّاه (`server.js`، `package.json`، `render.yaml`، `Dockerfile`، مجلد `public`، مجلد `src`، مجلد `tools`) — من زر **Add file → Upload files** أو بـgit.

## النشر على Render
1. ادخل على [render.com](https://render.com) واربط حساب GitHub.
2. **New → Blueprint** واختار المستودع. Render بيقرأ `render.yaml` لحالو وبيعمل خدمة اسمها `alqimma`.
3. استنى البناء (دقيقة أو دقيقتين)، وبعدين افتح الرابط اللي بيعطيك ياه.
4. رابط التجربة لحالك: `https://اسم-الخدمة.onrender.com/?demo=1`

> الخطة المجانية بتنام إذا ما حدا فاتها ربع ساعة، فأول فتحة بعد النوم بتاخد حوالي 30 ثانية.

> إذا بدك تنشر على منصة تانية بتدعم Docker، في `Dockerfile` جاهز.

## الإحصائيات
- من Render افتح الخدمة ← **Environment** وانسخ قيمة `STATS_KEY` (انولدت تلقائياً).
- افتح: `https://اسم-الخدمة.onrender.com/stats?key=القيمة`
- بالخطة المجانية الإحصائيات بتنحفظ بملف وممكن تنمسح مع إعادة النشر. لتنحفظ دايماً: اعمل قاعدة **PostgreSQL** على Render، وضيف متغير `DATABASE_URL` بقيمة الـ Internal Database URL.

## تعديل الأسئلة
الأسئلة بمجلد `src/q` (ملف لكل مجال). كل سؤال: `["السؤال","الجواب الصح","غلط","غلط","غلط"]` والخيارات بتتخربط تلقائياً.
بعد التعديل شغّل `npm run build` لتتحدّث `public/questions.js`، أو عدّل `public/questions.js` مباشرة.

## تشغيل على جهازك
```
npm install
npm start
```
وافتح `http://localhost:3000`.
